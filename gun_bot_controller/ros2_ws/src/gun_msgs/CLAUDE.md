# gun_msgs — custom ROS2 message package

Defines the message types used on the `/gun/*` topics between
`gun_controller` and `cloud_bridge`. Lives at
`gun_bot_controller/ros2_ws/src/gun_msgs/`.

These `.msg` files are the canonical schema. Don't redefine them
elsewhere — if you need to change a field, edit the `.msg` here and
bump the protocol version in [`../../../../IPC.md`](../../../../IPC.md).

## Messages

| Type | ROS2 field shapes | Used on | Maps to IPC.md |
|---|---|---|---|
| `Target` | `float64 yaw_centideg`, `float64 pitch_centideg` | `/gun/target` | `MSG_SET_TARGET` |
| `Mode` | `uint8 mode` + `MODE_MANUAL`/`AUTO`/`SAFE` constants | `/gun/mode` | `MSG_MODE` |
| `Fire` | `uint16 duration_ms`, `uint8 pressure` | `/gun/fire` | `MSG_FIRE` |
| `State` | `Mode mode`, `bool acked`, `uint8 ack_status`, `uint16 alert`, `uint8 error_flags` | `/gun/state` | derived from `MSG_ACK` + `MSG_ALERT` |
| `Telemetry` | yaw/pitch pos, `batt_mv`, `temp_c`, `ServoDiag[]` | `/gun/telemetry` | `MSG_TELEMETRY` + `MSG_SERVO_DIAG` |
| `ServoDiag` | `servo_id`, `position`, `load`, `voltage_mv`, `temp_c` | (nested in `Telemetry`) | `MSG_SERVO_DIAG` payload |

## Conventions

- **Centidegrees for angles**, not radians — matches `IPC.md`'s
  `i16 centi-deg` wire format and avoids float→int conversion in
  the hot path. `Target` uses `float64` for ergonomics;
  `Telemetry` uses `int32` for the actual measured positions.
- **Enums as `uint8` constants**, not ROS2 enum types (which don't
  exist as a first-class concept).
- **Units in field names** (`_mv`, `_ms`, `_centideg`, `_c`) so the
  schema is self-documenting.
- **No timestamps** in the messages themselves — ROS2 stamps them
  automatically on publish.

## When M4 starts

`ros2_ws/` will get a top-level `colcon` workspace:

```
gun_bot_controller/ros2_ws/
├── src/
│   ├── gun_msgs/              # ← this package
│   ├── gun_controller/        # the ROS2 node that bridges ROS2 ↔ M33
│   └── cloud_bridge/          # the ROS2 node that bridges ROS2 ↔ server
├── build/                     # colcon output (gitignored)
├── install/                   # colcon output (gitignored)
└── CLAUDE.md                  # cross-compile + deploy workflow
```

`package.xml` and `CMakeLists.txt` for `gun_msgs` are generated by:

```bash
cd gun_bot_controller/ros2_ws/src
ros2 pkg create --build-type ament_cmake gun_msgs
# then move the .msg files in and add rosidl_generate_interfaces()
```

(See [`../CLAUDE.md`](../../CLAUDE.md) for the full Phase 1 setup.)
